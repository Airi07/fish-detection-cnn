# Fish Detection & Classification System (CNN + Gradio)

An end-to-end Computer Vision system that classifies fish species using a Convolutional Neural Network (CNN) and provides an interactive web UI built with Gradio.

---

## Key Features

- **CNN Classification Model:** Custom CNN architecture trained to recognize fish species categories.
- **Interactive Gradio Interface:** Interactive web UI allowing users to upload images for real-time inference and confidence metrics.
- **Data Preprocessing Pipeline:** Image augmentation, scaling, and training routines developed in Jupyter Notebooks.
